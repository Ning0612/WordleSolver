📖 How to Use

▼
1. ⌨️ Enter Letters

Type using your keyboard or click the virtual keyboard below. Letters will be automatically added to the current row.

2. 🎨 Mark Colors

Click each cell to cycle through colors: Gray → Yellow → Green

  • Gray: Letter not in the answer
  • Yellow: Letter in answer, wrong position
  • Green: Letter in answer, correct position

Tip: Press Space to cycle colors for the current cell.

3. ✅ Submit Your Guess

After marking all 5 letters, click "Submit Current Row" or press Enter to get recommendations.

4. 💡 Use Recommendations

Two types of word suggestions will appear:

  • Candidate: Possible answers based on current clues
  • Exploration: Words to gather more information

Click any recommended word to auto-fill it in the next row.

5. 🔄 Reset Game

Click the "Reset" button to clear the entire grid and start a new game.
